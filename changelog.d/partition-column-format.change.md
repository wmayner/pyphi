The `partition` column of `LandscapeSection.df` and `OptimizationResult.to_pandas()` uses the same string as `SystemIrreducibilityAnalysis.to_pandas()`, such as `2 parts: {AB,C}; cut C→A, C→B`, so partition columns from these tables can be compared and joined. Sections and results saved by the release candidates, which wrote strings such as `[[0, 1], [2]]|[(2, 0), (2, 1)]` and `NullCut`, are given the new strings when they load.
