`analysis.ces` is a `CauseEffectStructure` under every version of IIT. Under IIT 3.0 it used to be the bare distinctions; it now holds them as `.distinctions`, with empty `.relations` and the system irreducibility analysis as `.sia`, so `len(ces.distinctions)`, iteration and `ces.distinctions.phis` work the same way under every version. `System.ces()` and `analyze(..., compute="ces")` return the same type, and under IIT 3.0 they now compute the system irreducibility analysis that the structure embeds; `estimate_analysis(compute="ces")` counts its system partitions under IIT 3.0 too. Under IIT 3.0, the structure's card shows no relation rows, and `Analysis.to_pandas()` and sweep rows report `sum_phi_r` as `NaN`. IIT 3.0 analyses saved by the 2.0.0 release candidates load as the new type. `Distinctions.phis`, `.mechanisms` and `.purviews(direction)` return tuples instead of single-use generators. `Relation.purview` is always a `frozenset`; self-relations already returned one, other relations returned a mutable `set`. Two `LandscapeSection`s with the same contents compare equal instead of raising, and `LandscapeSection` and `Perturbation` are unhashable, as their mutable fields already made them in practice. `AnalyticalRelations.to_pandas()` returns the degree spectrum, one row per degree with the number of relations and their Σφ_r, instead of raising. The aliases `pyphi.models.Concept`, `System.null_concept` and the twelve short names in `pyphi.convert` (`b2l`, `l2b`, `l2s`, `b2s`, `s2l`, `s2b`, `b2l_sbs`, `l2b_sbs`, `to_md`, `to_2d`, `sbn2sbs`, `sbs2sbn`) are removed; each raises an `AttributeError` that gives its replacement. `System.apply_cut(partition)` is now `System.apply_partition(partition)`, likewise on `TransitionSystem` and `Transition`, and the `System` card labels the partition row "Partition".
