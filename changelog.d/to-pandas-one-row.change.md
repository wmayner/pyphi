`to_pandas()` on a single object, such as a system irreducibility analysis, a distinction, a perturbation or an estimate, returns a one-row DataFrame instead of a Series, so rows from different results concatenate with `pd.concat`, as `Analysis.to_pandas()` and sweep tables already do. The system irreducibility analysis names its units column `subset` (sorted unit indices, as in sweep tables) instead of `system`.
