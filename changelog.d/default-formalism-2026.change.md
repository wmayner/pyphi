The default formalism is now **IIT 4.0 (2026)** — `version="IIT_4_0_2026"` with `system_phi_measure="INTRINSIC_INFORMATION"`, which applies the intrinsic-information cap `φ_s = min{φ_c, φ_e, ii(s)}` (Eq. 23). The previous default was IIT 4.0 (2023) with `GENERALIZED_INTRINSIC_DIFFERENCE` (uncapped system φ). System φ values under the default may now be lower where the cap binds. Select `formalism="IIT_4_0_2023"` (or `pyphi.presets.iit4_2023`) for the uncapped IIT 4.0 system φ, or `"IIT_3_0"` for IIT 3.0.
