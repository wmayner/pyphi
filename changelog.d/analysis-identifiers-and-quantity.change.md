`Analysis.to_pandas()` starts with `formalism`, `subset` and `state` (the substrate's state) columns, spelled and filled as in sweep tables, and `current_state` (the subset's state), as in the SIA's own row. Single analyses can be concatenated with sweep rows: the shared columns line up, and only the sweep has `substrate` and only the analysis `current_state`. `pyphi.optimize` takes the name of the quantity to optimize as `quantity=`, as `perturb` does, instead of `objective=` (it still accepts a callable), and `OptimizationResult.objective_name` is now `quantity_name`; files saved by earlier release candidates still load. `pyphi.macro.estimate_search` takes the arguments of `SearchBounds.estimate`: `estimate_search(substrate, *, bounds=None, limit=1_000_000)` instead of `estimate_search(bounds, n, limit)`, and `limit` is keyword-only on both.
