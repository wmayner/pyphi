More configuration values are rejected when they are written instead of failing or being ignored at compute time: an `actual_causation.version` that is not registered, an `actual_causation.alpha_measure` that version does not accept, `parallel_workers = 0`, an unknown `parallel_backend`, a `memory_ceiling_percentage` outside 0 to 100, a per-level parallel mapping whose `parallel` or `progress` is not a bool or whose `chunksize` is not a positive integer (NumPy booleans and integers count, and are stored as Python values), and an empty tie-resolution list. The error for an actual-causation measure no longer recommends the IIT presets.
