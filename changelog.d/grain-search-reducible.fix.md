The grain search (`pyphi.analyze(..., grains=True)` and `pyphi.macro.complexes`) no longer reports reducible systems as complexes. Candidates with φₛ = 0 used to reach the exclusion cascade, so a substrate where every candidate is reducible returned a complex with φₛ = 0, while `Substrate.complexes` returned none. Now such candidates are dropped before the cascade, the result's `complexes` is empty in that case, and a complex's `excluded` record lists only rivals with φₛ > 0, as on the micro grain. No φ value changes. The `ComplexesResult` returned by the search now prints as a card: its complexes with their φₛ, units and grains, the number of candidate systems evaluated, and the number of tied cliques. Before, printing it dumped every evaluation record, each with its full substrate. Its `to_pandas()` returns one row per complex.
