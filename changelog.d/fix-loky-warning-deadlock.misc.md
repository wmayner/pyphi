Fixed a flaky whole-suite test deadlock: under `filterwarnings = ["error"]`, loky's "A worker stopped while some jobs were given to the executor" `UserWarning` — emitted inside the executor-manager thread when a worker's idle timeout coincides with pending work — was escalated to an error, killing the manager thread without marking the executor broken. The reusable executor was then reused as a zombie and the next parallel test blocked forever in `future.result()`. The pytest configuration now keeps that specific message a visible warning, with a canary test guarding the exemption.
