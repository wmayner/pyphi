Purview labels in distinction cards, the distinction table and `plot_ces` are now written in the state the distinction specifies, as the documentation describes: uppercase for ON, lowercase for OFF, and a subscript for a value above 1 (`P₂`). They were written in the current state of the purview units, which reversed the label wherever the two states differ. Under IIT 3.0, which has no specified states, purview labels are uncased. The plot data's `EndpointNode.purview_state` is now `specified_state`. No φ value changes.
