`build_substrate`, `build_tpm`, `pyphi.weight_axis` and `pyphi.weight_axes` raise `TypeError` for a keyword that none of the unit functions takes, with a suggestion for a near match. A misspelt keyword such as `temprature=` used to be ignored, which built a different substrate without any error. A unit function of your own that accepts `**kwargs` can read any keyword, so keywords are not checked when one is among the unit functions.
