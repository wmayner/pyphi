`SweepResult.df` is long-format: it always has the columns `substrate`, `formalism`, `subset` and `state` and a default `RangeIndex`, however many values each axis has. Before, an axis became an index level when it had more than one value, so `df["state"]` raised a `KeyError` when two states were swept. Rows for `compute="ces"` and `compute=None` have the columns of `Analysis.to_pandas()`, including `big_phi` (Φ) and `sum_phi_d`; rows for `compute="distinctions"` have `n_distinctions`, `sum_phi_d` and `congruence`. `sweep` validates its axes before computing anything: numpy integer states and 2-D arrays are accepted, a single subset tuple is accepted like a single state, and empty axes and unknown strings raise `ValueError`. Sweeps saved by 2.0.0rc1–rc3 load in the long format, with `big_phi` and `sum_phi_d` filled in from the stored structures. `SweepResult`, `LandscapeSection` and `Perturbation` print compact cards instead of every analysis they hold.
