System specified-state ties now follow the full S1 postulate ladder
(Albantakis et al. 2023, S1). Readings tied at φ_s — the capped value under
IIT 4.0 (2026) — escalate to Composition: the reading with maximal structure
integrated information Φ is selected (computed lazily; the mechanism sweep is
shared and each tied reading pays only congruence resolution plus the
closed-form relation sum). A Φ tie among readings with intrinsically
identical (relabeling-isomorphic) structures is extrinsic: a canonical
representative is reported with the tie surfaced on `sia.ties`. A Φ tie among
genuinely distinct structures violates the information postulate: the SIA is
null with the new reason `NONUNIQUE_SYSTEM_STATE`. When every tied reading
has φ_s = 0 (under the 2026 default, every deterministic system), nothing
remains for Φ to adjudicate: no cause–effect structure is computed and the
reported state is a canonical presentational representative. Previously all
unresolved state ties fell directly to the canonical tie-break, so results
for systems with positive-φ_s state ties may change (Φ can only select a
reading with at least as much structure).
