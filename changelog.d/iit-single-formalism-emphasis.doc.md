The MCP reference content, the bundled `pyphi` and `iit` skills, and the package docstring now describe the theory PyPhi computes as IIT, citing Albantakis et al. (2023) and Mayner, Marshall & Tononi (2026) together. Earlier versions are covered in the `configuration` and `migration` references. The `configuration` reference also corrected an example that passed `formalism="iit3"`, a name `analyze()` rejects; the version name is `"IIT_3_0"`.
