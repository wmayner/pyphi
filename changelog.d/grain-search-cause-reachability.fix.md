The grain search (`pyphi.analyze(..., grains=...)` and `pyphi.macro.complexes`) no longer discards candidate systems whose state is reachable only through the background's past. `MacroSystem` checked reachability on its effect TPM, which holds the background at its current state, so it rejected such systems and the search treated them as having φₛ = 0; it now checks the cause TPM, which weights the background's past by its posterior (Marshall et al. 2026, Eq. 34). On affected substrates the grain search returns different complexes than before, and with `SearchBounds(max_depth=0)` it now returns the same complexes as `Substrate.complexes`.
