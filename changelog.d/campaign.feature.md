Added `pyphi.campaign`: distribute sweeps across an HTCondor pool as self-contained batch campaigns — `prepare()` writes a campaign directory with cost-balanced task packing and a generated submit file, `python -m pyphi.campaign run` executes one task, and `status()`/`collect()` reassemble the exact local-sweep result from per-task output files. Includes `prepare_campaign`/`campaign_status`/`collect_campaign` MCP tools and a campaigns how-to.
