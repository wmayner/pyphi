`create_substrate` and `substrate_generator.composite` raise `TypeError` for a node spec or sub-spec key they do not use (such as `parms` for `params`) and for a parameter that the mechanism or the combination does not take (such as `determinsm`), with a suggestion for a near match. Misspelt keys and parameters used to be ignored, which left the parameter at its default and built a different substrate without any error.
