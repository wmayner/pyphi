`System.sia()` and `System.ces()` check that the system's state is reachable under the formalism in effect for the call, whether selected with `formalism=` or with `config.override(...)`, as `pyphi.analyze` does, and raise `StateUnreachableForwardsError` when it is not. A system built under IIT 4.0 and computed under IIT 3.0 in a state IIT 3.0 cannot analyze returned a null result (Φ = 0) instead. `Substrate.all_sias`, `complexes` and the other complex functions make the same check on a `System` given as a candidate, before skipping duplicates. A system built with `config.infrastructure.validate_system_states` off is not checked.
