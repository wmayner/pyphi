`System.ces(sia=..., distinctions=...)` raises `ValueError` when the precomputed analysis names other units or another state than the system, or when a distinction's mechanism or purviews lie outside the system or its mechanism state differs from the system's state. These results were used as given, so an analysis of another state silently changed the reported Φ. `campaign.prepare_ces(sia=...)`, `campaign.collect(sia=...)` and the MCP server's `prepare_ces_campaign(sia_ref=...)` make the same check; `prepare_ces` makes it before writing the campaign directory.
