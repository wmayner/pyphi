First-run behavior: `pyphi.__version__` is available again. Names from 1.x (`pyphi.Network`, `pyphi.Subsystem`, `pyphi.compute`, `pyphi.jsonify`, and `examples.*_network` / `*_subsystem`) raise an `AttributeError` that gives the replacement. `estimate_analysis` accepts a state as its second argument, so it can be called like `analyze(substrate, state)`; the counts do not depend on it. Unknown node labels raise a `ValueError` listing the known labels instead of a bare `KeyError`. Importing PyPhi no longer creates `__pyphi_cache__/` in the working directory; the directory appears when something is first cached to disk. Running `pyphi-mcp` without the `mcp` extra says how to install it.
