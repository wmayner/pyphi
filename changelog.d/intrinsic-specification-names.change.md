The per-direction value a specified state maximizes is now called intrinsic specification under every version of IIT, following Mayner, Marshall & Tononi (2026, Sec. 2.3). On `StateSpecification`, `intrinsic_information` is renamed `intrinsic_specification` and `runner_up_intrinsic_information` is renamed `runner_up_intrinsic_specification`. `sia.intrinsic_information` keeps its name: it is ii(s), the minimum of intrinsic differentiation and intrinsic specification, and the third term of φₛ. Result cards label the per-direction value "Intrinsic specification" under IIT 4.0 as published in 2023 as well, and `explain()` reports the specified-state margins as `(i_spec)`. The analysis card no longer shows an ii(s) row for a result computed under a version that does not use ii(s) in φₛ. The functions that find a specified state are renamed the same way: `System.intrinsic_information()` is now `System.intrinsic_specification()`, `pyphi.core.repertoire_algebra.intrinsic_information()` is now `intrinsic_specification()`, and `pyphi.formalism.iit4.system_intrinsic_information()` is now `system_intrinsic_specification()`. The `INTRINSIC_INFORMATION` measure, which computes ii, keeps its name. The `analyze` tool of the MCP server omits `intrinsic_information` and `requirement_binding` from its summary for a result whose formalism does not use ii(s), as the analysis card does. The current state of a purview's units is now `mice.current_state` (formerly `purview_state`), and the corresponding `to_pandas()` column is `current_state`; the specified state is `mice.specified_state.state`. Files saved by 2.0.0rc1–rc3 load with the new names.
