The `subset` column of a sweep or campaign table holds sorted node indices however the subset was given, so labels, indices and reordered tuples for one system share one key, and a table built from mixed spellings can be saved. Subsets that name the same units run once, as repeated formalisms already did; a state given more than once still gives one row each time, so states sampled with replacement keep their duplicates. The `state` column holds unit-state indices. Invalid subsets and states, including boolean masks, non-integer numbers and nested sequences, raise a `ValueError` naming the problem before anything is computed; the MCP `prepare_campaign` tool reads a flat list as one state or subset.
