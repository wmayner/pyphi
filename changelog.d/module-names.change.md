The modules that define `analyze`, `sweep` and `optimize` are now `pyphi.analysis`, `pyphi.sweeps` and `pyphi.optimization`. The old module names were hidden by the functions of the same name, so `pyphi.sweep.SweepResult` raised `AttributeError` and the API reference had no pages for `Analysis`, `SweepResult` or `OptimizationResult`. The functions and classes are unchanged at the top level (`pyphi.analyze`, `pyphi.Analysis`, and so on), and saved files load as before. `pyphi.__all__` is now an explicit list of the public names and modules, so `from pyphi import *` no longer binds internal modules such as `log`, `cache` and `utils`; `pyphi.models.__all__` no longer lists private names, and `pyphi.actual` declares an `__all__` of its documented functions.
