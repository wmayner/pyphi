Every way of writing a misspelt option to `pyphi.config` now raises `ConfigurationError` with a suggestion. Writing an unknown dotted path (`pyphi.config["iit.mechanism_phi_measur"] = ...`, `config.override({...})` or a `pyphi_config.yml` entry) used to raise a bare `KeyError`, and a config-file section that is not a mapping raised `AttributeError`. A measure, partition scheme or tie-resolution strategy that is not registered is reported as unregistered, with the closest registered name, instead of as incompatible with the version; and `config.override` of the version alone now says to apply the preset, as item assignment does. Reading an unknown path with `pyphi.config[...]` still raises `KeyError`.
