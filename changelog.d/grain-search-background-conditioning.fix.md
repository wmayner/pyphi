The grain search (`pyphi.analyze(..., grains=...)`, `pyphi.macro.search.complexes` and the other search functions) and `MacroSystem.from_micro` raise `ValueError` when `config.formalism.iit.background_conditioning` is `"CONDITION_CURRENT_STATE"`. The macro cause TPM always marginalizes the cause-side background (Marshall et al. 2026, Eq. 34), so under that setting the search used to return φₛ values that disagreed with `Substrate.complexes` without any warning.
