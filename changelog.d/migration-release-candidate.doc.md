The migration guide and the MCP `migration` reference have a section for upgrading from a 2.0 release candidate. It lists the calls that return different numbers without an error (in rc1 to rc3, `subset=` and `formalism=` on `Substrate` and `System` methods were ignored), and every name that changed between rc3 and 2.0.0. The guide also has rows for the 4.0-branch names `purview_state` and `intrinsic_information`, the modules `new_big_phi`, `network_generator` and `metrics`, and the removed 1.x partition classes, and it says that a 1.x partition scheme value is rejected when written.
